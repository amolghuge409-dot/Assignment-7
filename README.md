# Assignment 7 - Personal Expense Tracker

A React app to record personal expenses and review monthly spending by category.

Features include expense entry and deletion, month filtering, spending summaries,
a daily spending chart, and category totals.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Expenses are saved in this browser's local storage only. They are not uploaded to GitHub or sent to a server.
